# ANHUAR — Landing page

Landing estática construida con HTML, CSS y JavaScript puro.

## Publicar en GitHub Pages

1. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets` a la raíz de tu repositorio.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main`, la carpeta `/ (root)` y guarda.

GitHub mostrará la URL pública cuando termine la publicación.

## Edición rápida

- Textos y enlaces: `index.html`
- Colores, tipografías y diseño: `styles.css`
- Menú y animaciones: `script.js`
- Fotografías y portadas: carpeta `assets`
